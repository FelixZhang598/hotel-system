## 执行记录模板

每次执行记录：用例 ID、时间、环境/版本、数据前置条件、请求或操作、实际响应、数据库核对、结论、证据文件。仅在实际执行后将状态改为通过或失败。

## 数据一致性核对

1. 对每个房型日期，reserved 与该日期未释放的 order_nights 数量一致，包括保留的历史记账。
2. 任一库存 reserved 在 0 和 total 之间。
3. 每间房最多一条未退房入住记录，每个订单最多一条入住记录。
4. CHECKED_IN 对应未退房记录；COMPLETED 对应已退房记录；CANCELLED/NO_SHOW 不得存在实际入住记录。
5. 事务失败前后对比订单、逐晚明细、库存、入住记录和事件，不能存在部分提交。
