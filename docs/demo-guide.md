# 五分钟演示

演示前启动本项目。若之前已多次操作，停止服务、显式重置演示数据库再启动。

1. 住客 guest1 登录：选择酒店今天入住、明天离店，展示房型余量、每晚价格和总金额，提交一张订单。
2. 打开我的订单和详情：展示订单号、已确认状态、日期和订单事件。解释离店日不占库存。
3. 退出住客，前台 frontdesk 登录：按订单号定位刚创建的订单，选择干净可用房间，填写虚构姓名和手机号，办理入住。
4. 展示订单已入住及房态占用。此订单明天离店，今天不能提前退房，页面应禁用或后端拒绝。
5. 切换预置的“今日离店、已入住”订单，办理退房；查看对应房间变为待清洁，点击清洁完成恢复可用。
6. 可选展示明日入住订单取消，库存释放；或展示未到店订单处理。并发演示使用接口验收记录，不在现场手工抢点击冒充并发验证。

建议截图：住客房型页、下单后的订单详情、前台分房弹窗、已入住详情、退房后的房态页。不要使用真实身份证、手机号等个人资料。

## 面试讲解顺序

- 先说明单酒店、无支付、单订单单间房的边界。
- 解释为什么房型逐晚库存与房间清洁/占用分开。
- 展示库存事务、幂等键、带原状态条件的更新和房间唯一约束。
- 展示实际接口并发验收结果，以及仍未执行的验收项（若有），不夸大验证程度。
- 打开需求、技术方案、实施计划、真实会话和 Agent 记录说明 AI Coding 过程。
